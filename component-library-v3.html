Checkbox

<tek-checkbox>

Binary selection control. Use for independent options. Supports checked, error, and disabled attributes.

default checked error disabled

Checked
Error

Interactive
HTML 
<!-- Default -->
<tek-checkbox></tek-checkbox>

<!-- Checked -->
<tek-checkbox checked></tek-checkbox>

<!-- Error state -->
<tek-checkbox error></tek-checkbox>

<!-- Disabled -->
<tek-checkbox disabled></tek-checkbox>

<!-- Listen for changes -->
document.querySelector('tek-checkbox')
  .addEventListener('tek-change', e => console.log(e.detail.checked));

CharacterCount

<tek-character-count>

Displays current character usage against a maximum. Set max and count attributes. Transitions to error styling at 100% capacity.

default focus filled disabled error
Default
Partial
Near limit
Error (at max)
Disabled
HTML 
<tek-character-count count="0"   max="140"></tek-character-count>
<tek-character-count count="72"  max="140"></tek-character-count>
<tek-character-count count="140" max="140" state="error"></tek-character-count>

<!-- Bind to an input -->
const input = document.querySelector('tek-input');
const counter = document.querySelector('tek-character-count');
input.addEventListener('tek-input', e => {
  counter.setAttribute('count', e.detail.value.length);
});
