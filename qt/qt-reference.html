Qt Reference

Token values translated to C++/Qt, QSS, and QML. Pick your format. Source of truth is always packages/tokens/src/.

⚠️
QSS has no variable system. All values are hardcoded. QSS does not support backdrop-filter (frosted glass) — use QGraphicsBlurEffect or a custom paintEvent instead. Alpha colors in QSS use rgba(r,g,b,0–255), not CSS's 0–1 float. For theme switching, swap between tek.dark.qss and tek.light.qss at runtime.

Quick Start

3 ways to use
Option A — C++ Header
Best for: instrument software, type-safe code, programmatic styling.
// 1. Copy qt/TekTokens.h into your project
// 2. Include it
#include "TekTokens.h"

// 3. Use it
QColor bg = Tek::Dark::Color::inputBackground;
label->setStyleSheet(
  "color: " + Tek::Dark::Color::inputTextDefault.name()
);

// Theme switching at runtime
auto t = Tek::Theme::Dark;
QColor c = Tek::themed(t,
  Tek::Dark::Color::buttonBgDefault,
  Tek::Light::Color::buttonBgDefault
);
Option B — QSS Stylesheets
Best for: existing Qt apps using stylesheets. Swap files to switch themes.
// Apply globally
QFile f(":/qt/tek.dark.qss");
f.open(QFile::ReadOnly);
QString ss = f.readAll();
qApp->setStyleSheet(ss);

// Switch to light
QFile fl(":/qt/tek.light.qss");
fl.open(QFile::ReadOnly);
qApp->setStyleSheet(fl.readAll());
Option C — QML Properties
Best for: modern Qt/QML UIs. Define once in a singleton, reference everywhere.
// TekTheme.qml — register as singleton
pragma Singleton
import QtQuick

QtObject {
  readonly property color inputBackground:
    "#252525"
  readonly property color buttonBorderDefault:
    "#33baea"
}

// In any QML component
Rectangle { color: TekTheme.inputBackground }
Alpha color note
The modal uses a semi-transparent background. CSS and QSS encode alpha differently.
/* CSS — RRGGBBAA */
background: #181818cc;

/* QSS — rgba(r,g,b, 0-255) */
background-color: rgba(24, 24, 24, 204);

/* C++ */
QColor(0x18, 0x18, 0x18, 0xcc);

/* QML — AARRGGBB */
color: "#cc181818"

Known Limitations

QSS gaps
Feature
Web (CSS)
Qt (QSS/C++)
CSS custom properties
✅ var(--tek-*)
❌ Hardcode values. Use TekTokens.h instead.
backdrop-filter (frosted glass)
✅ Native
❌ Use QGraphicsBlurEffect on a background widget + alpha fill on top layer.
Shadow DOM cascade
✅ Automatic
N/A — Qt uses parent/child widget hierarchy instead.
Dark/light toggle
✅ data-theme on <html>
⚠️ Manual — swap QSS file or conditional namespace at runtime.
Border radius: 9999px (pill)
✅ Native
⚠️ QSS supports border-radius but 9999px may render oddly — use half the widget height instead.
Variable fonts (wdth axis)
✅ font-variation-settings
❌ Qt's font engine doesn't expose variation axes. Use a pre-exported bold/semibold cut of Archivo.
Alpha in rgba()
✅ 0.0–1.0 or 0–255
⚠️ QSS rgba() uses 0–255 only. CSS #181818cc → rgba(24,24,24,204).

TekTokens.h

C++ header

Copy qt/TekTokens.h from the repo into your Qt project. All tokens live in the Tek:: namespace.

// Namespace structure
Tek::
  Primitive::Neutral::n100 … n900, black, white
  Primitive::Brand::tekBlue
  Primitive::UI::error, warning, success, shadow, backdropDark, backdropLight
  Font::geist, archivo, geistMono
  Font::Text::sizeXs … sizeXl, lineHeightXs … lineHeightXl
  Font::Heading::sizeXs … sizeXl, lineHeightXs … lineHeightXl, weight
  Dark::Color::modalBackground, inputBackground … (all semantic tokens)
  Light::Color::modalBackground, inputBackground … (all semantic tokens)
  Theme enum class { Dark, Light }
  themed(Theme, QColor dark, QColor light) → QColor

QSS Stylesheets

qt/tek.dark.qss · qt/tek.light.qss

Two files — one per mode. Add to your Qt resource system (.qrc) and load at startup. Swap at runtime to switch themes.

// Covered widget types
QWidget           — base colors and font
QLineEdit         — all border states (default, focus, disabled, error)
QTextEdit         — same as QLineEdit
QPlainTextEdit    — same as QLineEdit
QPushButton       — default, hover, pressed, disabled
QCheckBox         — indicator unchecked, checked, disabled
QRadioButton      — indicator unchecked, checked, disabled
QLabel            — base + role="input-label" + role="heading" variants
QFrame            — role="modal" (alpha background, no blur — see limitations)
QStatusBar        — footer equivalent
QScrollBar        — vertical, handle, hover

// Apply globally
QFile f(":/qt/tek.dark.qss");
f.open(QFile::ReadOnly);
qApp->setStyleSheet(f.readAll());

QML

TekTheme singleton pattern

Register a QML singleton and reference it anywhere. Alpha colors use #AARRGGBB format in QML.

// TekThemeDark.qml — register as singleton in qmldir
pragma Singleton
import QtQuick 2.15

QtObject {
  // Modal
  readonly property color modalBackground:     "#cc181818"  // AARRGGBB
  readonly property color modalBorder:         "#7b7b7b"
  readonly property color modalText:           "#ffffff"

  // Input
  readonly property color inputBackground:     "#252525"
  readonly property color inputBorderDefault:  "#7b7b7b"
  readonly property color inputBorderFocus:    "#ffffff"
  readonly property color inputBorderFilled:   "#afafaf"
  readonly property color inputBorderDisabled: "#454545"
  readonly property color inputBorderError:    "#e74848"
  readonly property color inputTextDefault:    "#979797"
  readonly property color inputTextFocus:      "#ffffff"
  readonly property color inputTextFilled:     "#cccccc"
  readonly property color inputTextDisabled:   "#454545"
  readonly property color inputLabelDefault:   "#cccccc"

  // Selector
  readonly property color selectorBgDefault:        "#252525"
  readonly property color selectorBgUnchecked:     "#454545"
  readonly property color selectorBgChecked:       "#cccccc"
  readonly property color selectorBorderUnchecked: "#7b7b7b"
  readonly property color selectorBorderChecked:   "#979797"
  readonly property color selectorBorderError:     "#e74848"
  readonly property color selectorLabelUnchecked:  "#cccccc"
  readonly property color selectorLabelChecked:    "#ffffff"

  // Button
  readonly property color buttonBgDefault:       "#1e1e1e"
  readonly property color buttonBgHover:         "#000000"
  readonly property color buttonBgInactive:      "#181818"
  readonly property color buttonBorderDefault:   "#33baea"
  readonly property color buttonBorderInactive:  "#454545"
  readonly property color buttonTextDefault:     "#cccccc"
  readonly property color buttonTextHover:       "#ffffff"
  readonly property color buttonTextInactive:    "#454545"

  // Footer / misc
  readonly property color footerBackground: "#252525"
  readonly property color footerText:       "#cccccc"
  readonly property color textLink:         "#33baea"
  readonly property color icons:            "#ffffff"

  // Type
  readonly property string fontBody:    "Geist"
  readonly property string fontHeading: "Archivo"
  readonly property string fontMono:    "Geist Mono"
  readonly property int    fontSizeMd:  13
  readonly property int    fontSizeLg:  14
  readonly property int    fontSizeXl:  16
}

// Usage in any .qml file
Rectangle {
  color: TekTheme.inputBackground
  border.color: TekTheme.inputBorderFocus
  border.width: 0.5
  radius: 5
}
