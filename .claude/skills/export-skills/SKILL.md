# Export skills to other LLM formats

The `.claude/skills/<name>/SKILL.md` files are the canonical source of truth for repo conventions. This skill regenerates equivalent rule files for other AI assistants so a Cursor / Windsurf / Cline / Copilot / Aider / Codex user gets the same guidance.

## Output map

| Tool | Output path | Format |
|---|---|---|
| Cursor | `.cursor/rules/<name>.mdc` | per-rule, MDC frontmatter |
| Windsurf | `.windsurf/rules/<name>.md` | per-rule, model-decision trigger |
| Cline | `.clinerules/<name>.md` | per-rule, plain markdown |
| Continue | `.continue/rules/<name>.md` | per-rule, name+description frontmatter |
| GitHub Copilot | `.github/instructions/<name>.instructions.md` | per-rule, `applyTo` frontmatter |
| Aider / Codex / Amp / Jules / Cody | `AGENTS.md` | single concatenated file |

## How to run

```bash
npm run skills:export
```

## Authoring rules

- Only edit `.claude/skills/<name>/SKILL.md`. Generated files carry an `AUTOGENERATED` header — never hand-edit them.
- Frontmatter requires `name` and `description`.
- Add `claude-only: true` to frontmatter for skills that depend on Claude Code features other tools cannot execute (hooks, slash commands, Claude-specific MCP servers). Those skills stay in `.claude/skills/` only.
- After editing any `SKILL.md`, run the export and commit both the source and the regenerated mirrors together.

## When to invoke

Whenever the user adds, removes, or meaningfully edits a `SKILL.md`. Also run as a sanity check before merging a PR that touches `.claude/skills/`.
