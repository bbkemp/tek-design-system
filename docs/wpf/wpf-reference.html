WPF Reference

Token values translated to WPF ResourceDictionary format. Every Color has a matching Brush. Source of truth is always packages/tokens/src/.

⚠️
WPF uses #AARRGGBB color format. CSS uses #RRGGBBAA but WPF puts the alpha channel first: #CC181818 = 80% opacity black. Each semantic token has both a Color key (TekColor*) and a SolidColorBrush key (TekBrush*). Use Brush keys in XAML bindings, Color keys when you need the raw Color struct in C#.

Quick Start

4 ways to use
ResourceDictionary Setup
Add token files to your App.xaml MergedDictionaries. Swap Dark/Light to switch themes.
<!-- App.xaml -->
<Application.Resources>
  <ResourceDictionary>
    <ResourceDictionary.MergedDictionaries>
      <ResourceDictionary Source="Tek.Tokens.Primitives.xaml"/>
      <ResourceDictionary Source="Tek.Tokens.Dark.xaml"/>
    </ResourceDictionary.MergedDictionaries>
  </ResourceDictionary>
</Application.Resources>
With Telerik
Load Telerik Fluent theme first, then Tek tokens override the Telerik brush aliases.
<ResourceDictionary.MergedDictionaries>
  <ResourceDictionary Source="/Telerik.Windows.Themes.Fluent;component/Themes/Generic.xaml"/>
  <ResourceDictionary Source="Tek.Tokens.Dark.xaml"/>
  <ResourceDictionary Source="Tek.Telerik.Overrides.xaml"/>
</ResourceDictionary.MergedDictionaries>
C# Code-behind
Access token values programmatically via FindResource. Cast to the appropriate type.
// Color struct
var color = (Color)FindResource(
  "TekColorButtonBackgroundDefault");

// SolidColorBrush
var brush = (SolidColorBrush)FindResource(
  "TekBrushButtonBackgroundDefault");

// Double (font sizes, line heights)
var size = (double)FindResource(
  "TekFontsTextSizeMd");
Alpha Colors Note
CSS and WPF encode alpha differently. The alpha byte swaps position.
<!-- CSS:  #RRGGBBAA -->
<!-- WPF:  #AARRGGBB -->

<!-- Example: 80% opacity dark -->
CSS:  #181818CC
WPF:  #CC181818

<!-- Example: 20% opacity black -->
CSS:  #00000033
WPF:  #33000000

<!-- Example: 80% opacity light -->
CSS:  #CCCCCCCC
WPF:  #CCCCCCCC (same by coincidence!)

Known Limitations

CSS vs WPF
Feature
Web (CSS)
WPF (XAML/C#)
CSS custom properties
✓ var(--tek-*)
✓ StaticResource / DynamicResource — same concept, different syntax.
backdrop-filter (frosted glass)
✓ Native
✗ No built-in blur. Use BlurEffect on a background element + alpha overlay.
Dark/light toggle
✓ data-theme on <html>
⚠️ Swap Tek.Tokens.Dark.xaml / Light.xaml at runtime via MergedDictionaries.
Border radius: 9999px (pill)
✓ Native
⚠️ CornerRadius works but 9999 may clip oddly. Use half the element height.
Variable fonts (wdth axis)
✓ font-variation-settings
✗ WPF does not support variable font axes. Use a pre-exported SemiBold cut of Archivo.
Alpha color format
#RRGGBBAA
#AARRGGBB — alpha byte comes first in WPF.
Dual Color + Brush keys
N/A — CSS has one value

Token Files

ResourceDictionary XAML

Copy the wpf/ folder from the repo into your WPF project. Reference via MergedDictionaries.

<!-- File structure -->
wpf/
  Tek.Tokens.Primitives.xaml    <!-- neutral palette, brand, UI, fonts, spacing, borders -->
  Tek.Tokens.Dark.xaml          <!-- semantic Color + Brush keys for dark mode -->
  Tek.Tokens.Light.xaml         <!-- semantic Color + Brush keys for light mode -->
  Tek.Telerik.Overrides.xaml    <!-- maps Tek tokens to Telerik Fluent brush aliases -->

<!-- Key naming convention -->
Color key:  TekColor{Component}{Property}{State}
Brush key:  TekBrush{Component}{Property}{State}

<!-- Examples -->
TekColorButtonBackgroundDefault   → Color
TekBrushButtonBackgroundDefault   → SolidColorBrush
TekFontsTextSizeMd                → sys:Double
TekSpacingS05                     → Thickness
TekBordersRadius03                → CornerRadius
TekFontsFamilyGeist               → FontFamily

<!-- Theme switching at runtime -->
var merged = Application.Current.Resources.MergedDictionaries;
var darkDict = new ResourceDictionary {
  Source = new Uri("Tek.Tokens.Dark.xaml", UriKind.Relative)
};
var lightDict = new ResourceDictionary {
  Source = new Uri("Tek.Tokens.Light.xaml", UriKind.Relative)
};

// Remove old, add new
merged.Remove(darkDict);
merged.Add(lightDict);

<!-- XAML binding with DynamicResource (reacts to theme swap) -->
<Button
  Background="{DynamicResource TekBrushButtonBackgroundDefault}"
  BorderBrush="{DynamicResource TekBrushButtonBorderDefault}"
  Foreground="{DynamicResource TekBrushButtonTextDefault}"/>
